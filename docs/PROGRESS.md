## Assumptions log

- **4 Nov 2026 (PRD 15 Q1–Q14):** documented defaults in use, as listed in the table above.
- **4 Nov 2026 (ADR 0002):** PGlite was used so tests run without Docker. It stays acceptable for unit and integration tests only; R1 replaces it at runtime.
- **4 Nov 2026 (DESIGN 9.1):** `--ink-2` used for secondary text on `--tint` rows where `--ink-3` fell below 4.5:1.

- **8 Nov 2026 (ADR 0005):** one role per user (PRD 2.1 allows several); dashboard bars drawn with CSS and DESIGN tokens instead of a chart library; reporting currency USD with unconverted amounts listed, never guessed.
- **8 Nov 2026 (ADR 0006):** first-reply SLA warning four hours before the deadline (PRD 4.16 gives no number); breach alerts go to the assignee and the active Sales Managers and Admins of the task's team.

- **11 Nov 2026 (ADR 0012):** development can use a separate PostgreSQL made by `pnpm db:local init` on port 5433 when the installed server's `postgres` login is not available. It is for development data only and is not a Windows service.
- **11 Nov 2026 (ADR 0011):** global search's fuzzy match uses pg_trgm's default similarity of 0.3 (it was 0.2), because only the `%` operator can use the trigram indexes; substring matches are unchanged. A full scan counts as a finding from 20,000 rows. Tasks have indexes only for the due and completed sorts the screens use.
- **10 Nov 2026 (ADR 0010):** the Admin role receives the PRD's "Super Admin" alert for exports over 1,000 rows, as an in-app notification (email comes with the Microsoft 365 connector). Export files are kept 7 days. One export holds at most 100,000 rows, the same as the import limit. Downloads go through the authenticated API instead of a signed link.
- **10 Nov 2026 (ADR 0009):** "Do not contact" from either record wins in a merge and is never lifted by an undo. Sequences stopped because both contacts were in them come back paused, not running. The PRD's `merge_snapshots` is the existing `merge_logs` table. A pair someone marked as not duplicates is never queued again.
- **10 Nov 2026 (ADR 0008):** imported contacts without a title, job function or seniority keep those blank (the create form's "Partner" defaults are not applied); companies without a firm type get "Other". A contact row without a website links to an existing company with exactly the same name in the same country.
