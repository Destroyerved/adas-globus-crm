# Operations Runbooks

Runbooks are added alongside their operational capabilities in Phase 1+:

- `deploy.md` — Production deployment and rollback (`scripts/deploy.sh`, Phase 1)
- `restore.md` — Off-site backup restore and monthly drill (`scripts/restore-drill.sh`, Phase 1)
- `rotate-keys.md` — Token encryption key and Entra credential rotation (Phase 1)
- `offboard-user.md` — Immediate user deactivation and session revocation (Phase 1)
- `incident.md` — Incident response, auto-paused campaigns, and tunnel outages (Phase 1/5)
